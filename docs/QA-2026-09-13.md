# Local QA and implementation report — September 13, 2026

This report covers the source prepared for VibePBL Desktop 2.0.0.

## Completed

- Problems can belong to multiple learning objectives. Duplicate links within one objective are removed; unlinking one objective does not affect the others.
- Added in-app reference lookup beside Clarifying terms: exact-first definitions from a bundled MeSH 2026 SQLite index, broader MedlinePlus topic overviews, editable excerpts, direct term creation, glossary destination selection, retrieval dates, and source attribution. The offline index contains 31,110 descriptors and 267,012 preferred or entry terms; partial words and minor misspellings are ranked locally. Up to ten results are shown and related topics are clearly distinguished from exact definitions. No account or API key is required. Neutral app-owned icons are used.
- Added optional Google and DuckDuckGo web search in a separate VibePBL browser window, with a local browser-style toolbar containing Back, Forward, current address, and Close controls. Remote pages cannot invoke workspace commands; non-HTTPS/local navigation, downloads, Google account sign-in, and external pop-ups are blocked. It uses private WebView storage but websites remain governed by their own privacy/cookie policies.
- Lookup validates queries and responses, safely displays remote text, limits response size and request frequency, reuses its HTTP client, and uses bounded memory plus persistent SQLite caches. The MeSH fast path is fully offline; MedlinePlus remains online.
- Hardened reusable dialogs so titles, labels, choices, and user-entered edit values are escaped centrally. Imported images are limited to 50 MB, session-field IPC payloads are capped at 10 MB, presenter imports/names are bounded and single-line, and remote reference pages are not granted clipboard API access.
- Reworked non-Retro layouts toward a tighter, flatter information-first interface and removed the global DOM mutation observer used for autocomplete suppression. Large repeated cards use deferred rendering hints where supported.
- Windows debug and release builds now always use the GUI subsystem, preventing an extra Command Prompt window from opening beside VibePBL.
- Serialized autosaves with edit-time snapshots, coalescing, retry preservation, and save-before-close/reset. Failed saves prevent closing. Fixed the permission needed for Tauri's close handshake. macOS Quit is routed through that handshake too.
- Improved drag reordering with scroll-container auto-scroll, cancellation and navigation cleanup, pointer tracking, and an Alt+Up/Down keyboard alternative without visible arrow buttons.
- Stabilized presenter assignment keys across reordered/shared problem links, migrated old keys, persisted presenter names, canceled abandoned draw animations, and retained immediate assignment after each draw.
- Optimized the usual paired two-round draw to linear work while maintaining balanced allocation and different presenters for matching main/subtopic numbers.
- Printing waits for fonts and images and reports missing resources instead of silently printing blank images. Recognizes the macOS desktop protocol rather than accidentally falling back to browser storage if the native bridge is missing. Image picking now uses an asynchronous dialog.
- Added native data-shape validation and explicit errors for corrupt stored data. Removed the unused SQL plugin and its dependency chain; SQLite remains managed by the existing native backend.
- Added Windows/macOS CI checks and documented setup, privacy, and lookup behavior in the README.
- Reduced GitHub Actions permissions to read-only outside the publishing job and pinned every build action to a reviewed commit hash.

## Verification

Passed locally on Windows:

- Frontend syntax checks and regression tests, including shared links, migration, save retries/races, print readiness, macOS-protocol fallback protection, and a 10,000-topic paired draw.
- Rust formatting and all fourteen native unit tests, including offline MeSH extraction, typo/partial matching, Google and DuckDuckGo history handling, presenter validation, and persistent-cache reuse.
- Optimized Windows executable build.
- Native app smoke tests with isolated test data: all eight workspace routes, Thai text, actual mouse-input drag reordering, hypothesis states, shared links and independent unlinking, live MedlinePlus lookup/cache, exact MeSH definition lookup, in-app web search/navigation and workspace isolation, unsafe-HTML fixture handling, excerpt persistence, presenter draws, sidebar/Retro/narrow layouts, image highlights/zoom, print preview, reset, and close/reopen with an immediately preceding edit. No captured native/frontend errors.

Test data is temporary and separate from the user's workspace data. The smoke test does not exercise the operating system's image picker or submit a physical print job.

## Dependency audit and remaining limits

The final npm audit reported zero vulnerabilities. The refreshed RustSec audit reported no vulnerability entries, but warnings remain for inherited unmaintained dependencies (`proc-macro-error` and the `unic-*` family) and a `glib` unsoundness advisory (RUSTSEC-2024-0429). Target-specific dependency checks found `glib` and `proc-macro-error` absent from Windows x64 and macOS ARM64 dependency trees; the GLib warning belongs to the Linux stack. The `unic-*` crates are inherited by the current patched Tauri 2.11.5 stack. These upstream warnings were not resolved by this update.

No real Mac was available. The release pipeline builds and tests macOS before publishing either download, but physical Mac checks are still recommended for first launch, import/cancel, drag and scrolling, live lookup, close/Cmd+Q persistence, and native print/Save as PDF with Thai text and case images. The underlying WebView print implementation requires macOS 11 or newer. Print preview and resource readiness were tested on Windows, not the macOS system print dialog.

This is a targeted bug and reliability review, not a guarantee that every bug has been found. MeSH and MedlinePlus are not an exhaustive medical dictionary. The bundled MeSH snapshot remains available offline; MedlinePlus and web-search availability depend on third-party public services.
